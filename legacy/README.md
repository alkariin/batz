# Legacy scripts

The original Python scripts that extracted PostFinance PDF statements
(`extract_v1.1.py`) and categorised their lines from a YAML mapping
(`analyze_v2.0.py`, `convert_config_v2.0.py`).

They are kept as a reference for the statement extraction of phase 3 and will
leave the repository afterwards. They read files placed next to them; the
statements and configurations they expect are personal and never committed.
